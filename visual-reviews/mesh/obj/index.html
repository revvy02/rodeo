OBJ import preserves concave faces

The importer now triangulates concave polygons in their face plane, preserving winding and corner attributes. Non-finite positions, UVs, and normals are rejected with source-line errors. UV seam checks now compare actual values.

Fixture, capture, and validation

concave.obj: one planar U-shaped face, expected area 7 square studs. Both captures use the same capture script, material, lighting, 35° camera, 960 × 720 viewport, and two-second settle time. Click either preview to open its full-resolution PNG.

  • Area, winding, UVs, and normals checked in XY, YZ, ZX, and an oblique plane, with both face windings.
  • Independent position/UV/normal indices checked using seams.obj, including different UVs at the same position.
  • NaN, infinities, and numeric overflow rejected; Studio confirms the error includes the source path and line.
  • Existing glTF/GLB roundtrips, skinning, large meshes, and over-limit errors pass.

Iteration notes: replaced fan triangulation with GeoRust Earcut and 3D face projection; added a triangulation-area check and finite-number validation.
